# Project brief

**Financial Metrics Dashboard**: an executive dashboard that shows a company's income, outcome (expenses), profit and profit margin over the last 12 months.

- **Origin**: 4Geeks Academy AI Engineering exercise (`4GeeksAcademy/ai-eng-financial-dashboard-context-project`). This fork is `zaba-la/ai-eng-financial-dashboard-context-project`.
- **Learning goal of the repo**: practice context engineering for coding agents. Inspect the code, write rules (`.agents/rules`), a memory bank (`memory-bank/`) and agent skills (`.agents/skills`), then refine them against the real workflow.
- **Product scope today**: a single read-only page. No auth, no persistence, no user input. Data is mock, generated by the backend.
- **Two apps in one repo**: `frontend/` (React + TS + Vite) and `backend/` (FastAPI), orchestrated with `docker-compose.yml`.

## Non-goals (unless explicitly requested)

- Real database or external data sources
- Authentication / multi-tenant
- Deployment configuration
